# Expense Tracker 💰

A simple Python program to track daily expenses.

## Features
- Add expenses with date/category
- Data saved in JSON format
- View all expenses

## How to Run
```bash
python expense_tracker.py
```

## Sample Data
Your `expenses.json` already contains:
```json
[{"date": "12-06-2005", "amount": 3652.0, "category": "Food"}]
```
